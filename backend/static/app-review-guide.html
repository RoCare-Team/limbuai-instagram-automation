Kaunse Instagram API permissions chahiye

Instagram API with Instagram Login (Business Login)

Yeh dashboard jo kaam karta hai (insights, comments manage, DM auto-reply), uske liye Meta ke 4 core scopes chahiye. Har ek ko App Review me alag se submit karna padta hai — apni alag description aur apni alag screencast ke saath (duplicate video/description allowed nahi hai).

instagram_business_basicLogin ke sath hi milta hai

Profile info (username, account type, media count) aur media list read karne ke liye. Isko review ki zaroorat nahi hoti — sabse basic scope hai.

Dashboard me use: /api/profile /api/media
instagram_business_manage_commentsReview chahiye

Comments read karna, reply karna, hide/delete karna — dono manual (dashboard se) aur automatic (webhook se).

Dashboard me use: /api/media/:id/comments /api/comments/:id/reply /api/comments/:id/hide
instagram_business_manage_messagesReview chahiye

DMs bhejne/receive karne ke liye — DM auto-reply rules yahi permission use karte hain.

Dashboard me use: send_dm_reply() · webhook messaging field
instagram_business_manage_insightsReview chahiye

Post-level insights (reach, likes, comments, shares, saved) fetch karne ke liye jo har media card pe dikhte hain.

Dashboard me use: /api/media/:id/insights
instagram_business_content_publishReview chahiye

Dashboard ke "Create a post" section se seedha Instagram feed pe image + caption publish karne ke liye.

Dashboard me use: /api/publish /api/publish/limit
Note: Purane scope names (instagram_manage_comments, instagram_manage_messages waghera bina business_ prefix ke) deprecated ho chuke hain. App Dashboard me sirf naye instagram_business_* scopes select karna — agar purane dikhein to app ko naye Instagram API product pe migrate karna padega.
2

Screencast video kaise banani hai

Har permission ki alag video

Recording setup

  • Resolution: 1080p ya usse zyada. Screen/monitor resolution 1440px width se zyada mat rakhna (reviewer ka screen chhota ho sakta hai).
  • Audio: Zaroorat nahi — reviewers audio nahi sunte. Video mute rakh sakte ho.
  • Language: App UI English me rakhna jab record karo, taaki reviewer samajh sake.
  • Mouse: Sirf mouse se navigate karo (keyboard shortcuts avoid karo) — mouse cursor thoda bada rakho taaki clicks clearly dikhein.
  • Frame: Sirf app window record karo (poori desktop nahi) — full screen app rakho.
  • Tools (free): Windows par Win+Alt+R (Xbox Game Bar) ya OBS Studio free hai. Paid: Camtasia, Snagit.

Har permission ki video me kya dikhana hai

Meta ka rule simple hai: (a) user app ko permission grant karte hue dikhna chahiye, aur (b) app us permission ko real feature me use karte hue dikhna chahiye.

  1. Login / permission grant — har video ki shuruaat meDashboard kholo (logged-out state me tumhe "Connect your Instagram business account" screen dikhega) → "Continue with Instagram" button click karo → Instagram ka permission screen aayega jaha saare scopes list honge → "Allow" dabao → wapas dashboard pe aa jaoge with account connected. Ye clip ek baar record karke chaaron videos ke start me laga sakte ho.
  2. comments permission → dashboard khol ke ek post click karoComments list dikhao → ek comment pe "Reply" click karke reply bhejo → phir "Hide" ya "Delete" bhi try karo. Ye instagram_business_manage_comments ki video hai.
  3. messages permission → auto-reply rule dikhao"Direct Messages" tab kholo → ek keyword rule add karo (jaise "price" → "DM us for pricing!") → phir kisi doosre test-account se us keyword wala DM bhejo aur dikhao ki auto-reply aa gaya (activity log me "auto_dm_reply" entry dikhao). Ye instagram_business_manage_messages ki video hai.
  4. insights permission → post insights kholoMedia grid me se koi post click karo → modal me reach/likes/comments/shares/saved ke numbers dikhao. Ye instagram_business_manage_insights ki video hai.
  5. content_publish permission → naya post banao"Create a post" section tak scroll karo → image choose karo (ya public image URL paste karo) → caption likho → "Publish to Instagram" dabao → "Published!" message dikhao → phir Instagram app/profile kholo aur dikhao ki post sach me live ho gaya. Ye instagram_business_content_publish ki video hai.
Reminder: Agar app khud-explanatory nahi hai to on-screen text captions/tooltips daal do jisme bata ho "ye button reply bhejta hai" waghera — reviewer ko context chahiye hota hai.
3

Video upload kaise karni hai

developers.facebook.com/apps → App Review
  1. App Dashboard kholodevelopers.facebook.com/apps → apna app select karo.
  2. App Review → Permissions and FeaturesLeft sidebar me "App Review" → "Permissions and Features" pe jao. Yaha upar bataye 4 scopes (comments, messages, insights, content_publish) dhundo — instagram_business_basic auto-approved hota hai isliye list me alag se nahi maangna padta.
  3. Har permission ke saamne "Request" click karoEk form khulega — "How is this used?" description likhna hoga (har permission ke liye alag, copy-paste mat karna) aur video upload karne ka option milega.
  4. Video file upload karoMP4 recommended. File size limit App Dashboard me hi dikh jayegi (usually kaafi bada limit hota hai, 1-2GB tak chal jata hai). Upload hone ke baad preview zaroor dekh lena.
  5. Business VerificationAgar app dashboard "Business Verification required" bol raha hai to pehle Meta Business Manager me business verify karna padega — ye alag se ek process hai jisme business documents chahiye hote hain.

Submit karne se pehle final checklist

Mistakes yahi hoti hain

✅ Karo

  • Ek clean test post/comment/DM pehle se ban lo taaki video me demo smooth chale
  • Har feature ka pura loop dikhao — click se result tak
  • Submit karne ke baad ~1 hafte wait karo, review team email pe reply karti hai agar kuch missing ho

❌ Mat karo

  • Ek hi video sab permissions ke liye reuse — har permission ki alag video chahiye
  • Keyboard shortcuts se navigate karna — sirf mouse clicks dikhao
  • Poori desktop record karna — sirf app window
